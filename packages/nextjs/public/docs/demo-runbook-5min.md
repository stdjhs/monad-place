# Monad Place · 5 分钟演示执行手册（傻瓜版）

> **原则**：台上的人只说话 + 按一个按钮，其余动作全部由幕后角色按本手册执行。
> **核对基准**：`main@d6a1a7c` 实际代码逐文件核对，本手册只收录【已存在】的功能，未实现的按「缺口对策」降级处理。
> 配套：`demo-assets.md`（30s 兜底录屏分镜）、README（对外口径）。

## 0. 功能现状核对表 ⚠️ 演示前必读

README 与分镜文档宣称、但**代码里没有**的功能——台下评委如果读过 README，这是最大风险点。**演示前必须二选一**：

| 宣称 | 代码实际 | 现场对策（本手册采用） |
| --- | --- | --- |
| `/campaign` 付费创建页 | ❌ 无此页面 | 改用 `/debug` 页直接调 `createCampaign`（同样是真实付费交易，见 2:00 段） |
| `/play` 终局铸 NFT | ❌ play 页只有封盘按钮 | 改用 `/debug` 调 `mint`，或纯话术带过 |
| 大屏「🎵 发起合唱」按钮 + 战报横幅 | ❌ stage 页无此功能 | 改为**主讲口播 3-2-1 倒计时**，读 TPS 仪表 + 总交易增量（数字是真的） |
| `/stage?replay=1` 回放模式 | ❌ stage 页不解析该参数 | 现场不提回放 |
| 画布预热脚本 | ⚠️ 仅支持本地链（`scripts/seedCanvas.mjs` 用 evm_increaseTime） | 测试网预热需提前手工跑，见 T-1 天清单第 6 项 |

**二选一决策**（T-1 天 18:00 前定）：
- A. 认怂版（推荐，稳）：按本手册对策走，同时把 README/落地页里上述功能改成「已上线合约层，前端下一迭代」。
- B. 冲刺版：赛前补齐 `/campaign` 页 + `/play` 铸造按钮（工作量约半天～一天），补齐后按 README 全量演示。

## 2. T-1 天准备清单（逐项打勾，全绿才睡）

- [ ] **测试网部署确认**：`yarn deploy --network monadTestnet` 全量跑通（含 CampaignFactory + PlaceCanvasNFT，终端应打印 `💰 CampaignFactory deployed` 与 `🏟️ PlaceCanvasNFT deployed`）。本机 `deployments/` 目前只有本地 `default/PlaceCanvas.json`，**测试网部署记录缺失，必须先补**。
- [ ] **双链路**：主站 `monad.ccwu.cc` 打开 `/play` 走通一次；Vercel 备用链接记入手册附录。
- [ ] **owner 钱包导入封盘手设备**：`yarn account:reveal-pk` 取私钥 → 导入设备 B 的浏览器钱包（测试网账户，无所谓）→ 连上 `/play` → **确认能看到红色封盘按钮**（只有 owner 钱包可见，看不到就是没导对）。
- [ ] **弹药包**：owner 钱包保留 ≥2 MON；另备 3 个已领水账户各 ≥0.3 MON。
- [ ] **托儿设备**：每台装好钱包、连上 `/play`、领好水、试落 1 子。
- [ ] **画布预热（可选）**：测试网手工预埋紫金图腾——任一账户每 3 秒可落 1 子（冷却按地址计），30 子约 2 分钟，开 3 个账户并行 1 分钟搞定。不预热也能演示，但开场大屏是全黑。
- [ ] **30s 兜底录屏**：按 `demo-assets.md` 分镜录，存笔记本 A 本地 + 手机各一份。⚠️ 分镜里「发起合唱」「回放」段按本手册口播版重写。
- [ ] **打印**：本手册 1 份 + A4 二维码 1 张（指向 `monad.ccwu.cc/play`）——大屏二维码依赖外链 `api.qrserver.com`，大陆网络不稳，纸质版是硬兜底。
- [ ] **决策 0 节 A/B 已定**。

## 5. 处置卡（故障时照抄，不思考）

- **卡A · 网络/投影断**：大屏手切手机热点（30 秒内）→ 不行就播 30s 兜底录屏，主讲照常念串词。
- **卡B · 观众没测试币举手**：封盘手过去收地址，空投 0.05 MON；主讲话术：「没币的朋友看大屏，你的队友正在替你战斗。」
- **卡C · 冷场没人落子**：托儿全员开打；主讲话术：「紫军已经动手了，金军就看着？」
- **卡D · `/stage` 显示「合约尚未部署」黑屏**：大屏手刷新页面；15 秒不恢复 → 卡A 录屏路径。
- **卡E · 被压缩到 3 分钟**：砍掉 1:45–2:45 商业段整段，改一句话带过（「三层收入模型详见落地页」）；合唱 + 封盘两个仪式**必须保住**。
- **卡F · 封盘交易卡 pending/失败**：等 15 秒重试一次；仍失败主讲收：「指纹正在区块里打包——链上数据稍后都在，我们等它，但观众不用等。」然后照常收尾。**不要现场 debug。**
